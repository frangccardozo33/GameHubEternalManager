# La Cupidité — prompts de gráficas (uno por archivo)

```
Contexto común (pegar antes de cada pedido):
Estás creando la identidad gráfica de «LA CUPIDITÉ», el torneo de copa de una liga de fútbol de un videojuego. Marca: trofeo en forma de
diamante tallado con dos asas, lema «AD ASTRA PER ASPERA». Paleta: negro #050807 de base, esmeralda #27D468 como color de marca,
esmeralda claro #6FFFA6 para brillos, esmeralda oscuro #0A3020 para sombras; blanco solo para números. Estilo: deportivo premium,
metálico oscuro, facetas geométricas de diamante, bordes esmeralda luminosos, tipografía itálica condensada, muy inclinada y angulosa.
Es una transmisión de TV: los textos y escudos los pone el juego encima, así que NO dibujes texto, escudos, jugadores ni logos ajenos
(salvo que se pida el logo). Entrega en PNG con transparencia real cuando se indique. Mantené el nombre de archivo y la proporción exactos.
```

## Encargos que no son imágenes
### A · Set 3D del estudio con la paleta de la copa
```
Sos un desarrollador three.js. En 01-futbol/tlb/graphics.js y 01-futbol/tlb/app.js está el estudio de análisis (dos presentadores y un set).
Cuando el partido es de La Cupidité (LFOBroadcast.pushPackage('cupidite') activo), quiero que el set use: mesa curva negra con filo esmeralda #27D468,
una pantalla de datos con el diamante del trofeo, fondo de ciudad nocturna y luces esmeralda. No cambies la lógica de los presentadores ni los textos.
Cuando se sale de la copa (popPackage) debe volver el set de la liga. Entregá solo los cambios en esos dos archivos.
```
### B · Cancha táctica 3D de las alineaciones
```
En 01-futbol/tlb/app.js está la presentación de alineaciones sobre una cancha táctica. Para La Cupidité, dibujá un marco de diamantes esmeralda alrededor de la cancha,
líneas blanco-esmeralda y una textura de césped oscura. Solo debe activarse con el paquete «cupidite». No modifiques las posiciones de los jugadores.
```
### C · Ceremonia de entrega del trofeo (no existe todavía)
```
Creá una animación 3D corta (8–10 s) para el campeón de La Cupidité: el trofeo-diamante (usá 01-futbol/lfoskin/cupidite/trophy-render.png como referencia visual o un modelo procedural)
desciende con luz esmeralda, gira lentamente, cae confeti esmeralda y aparece el nombre del club campeón. Se dispara cuando termina la final (tlm-cup.js marca al campeón). Debe poder saltarse con un botón.
```
